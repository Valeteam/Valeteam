## 👋 Ciao, sono Vale

Studente di **2° superiore** con la passione per la programmazione. Ho iniziato il **C++** a ottobre 2025, in gran parte da autodidatta: leggendo, sperimentando, rompendo cose e aggiustandole.

Scrivo codice, programmo server Minecraft e guido simulatori di rally. Due mondi diversi, stessa mentalità: **precisione** ed **ottimizzazione**.

- 💻 Sviluppo in **C++** e **C#**, e lavoro con **HTML/CSS** dal 2024
- 🖥️ Nei server **Minecraft** mi occupo di configurazione, plugin e ottimizzazione delle performance
- 🎬 Faccio da **Script Manager** e sviluppatore server per **Where Creativity Wins**
- 🏎️ Sono un **sim racer** specializzato nel rally
- 📚 Sto studiando **JavaScript**, **PHP** e **MySQL**
